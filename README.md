# WEBWERK

Landingpage für eine Webdesign-Agentur — *„Wir erstellen Webseiten, die Kunden gewinnen."*

Statische Single-Page-Website (HTML, CSS, Vanilla JS) im dunklen Design mit lime-grünen Akzenten.

## Aufbau

- `index.html` — Struktur der Seite (Header, Hero, Vorteile, Referenzen, CTA, Footer)
- `styles.css` — komplettes Styling, vollständig responsive
- `script.js` — mobiles Navigationsmenü

## Lokal ansehen

Einfach `index.html` im Browser öffnen — keine Build-Tools nötig.

```bash
# optional mit lokalem Server
python3 -m http.server 8000
# dann http://localhost:8000 öffnen
```

## Abschnitte

1. **Header** — Logo, Navigation, CTA
2. **Hero** — Headline, Badges und Geräte-Mockups (Laptop + Smartphone)
3. **Ihre Vorteile** — vier Leistungs-Kacheln
4. **Referenzen** — drei Projekt-Karten mit Kennzahlen
5. **Call-to-Action** — kostenloser Website-Check
6. **Footer** — rechtliche Links und Social Media
